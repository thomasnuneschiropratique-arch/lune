# Lune

Application web de suivi de cycle (méthode symptothermique à double contrôle : température basale + glaire cervicale).
Toutes les données restent sur le téléphone : aucun compte, aucun serveur, aucune analytique.

Lune n'est pas un dispositif médical et ses règles n'ont pas été validées par un professionnel de santé.
